---
title: What is Alita Robot?
description: Learn about Alita Robot, a powerful Telegram group management bot built with Go.
---

Alita Robot is a modern, feature-rich Telegram group management bot built with Go and the [gotgbot](https://github.com/PaulSonOfLars/gotgbot) library. It provides comprehensive tools for managing Telegram groups of any size.

## Key Features

<CardGroup cols={2}>
  <Card title="Moderation Tools" icon="shield-alert">
    <Badge variant="accent">Popular</Badge>

    - **Banning & Muting** — Ban, mute, kick users with optional reasons and time limits
    - **Warning System** — Configurable warning limits with automatic actions
    - **Antiflood Protection** — Prevent message spam with customizable limits
    - **Blacklists** — Automatically moderate messages containing blacklisted words
  </Card>

  <Card title="Content Management" icon="file-text">
    <Badge variant="accent">Core</Badge>

    - **Notes** — Save and retrieve text/media snippets with keywords
    - **Filters** — Auto-respond to keywords with custom messages
    - **Rules** — Set and display group rules
    - **Pins** — Advanced message pinning with anti-channel-pin protection
  </Card>

  <Card title="Automation" icon="rocket">
    <Badge variant="success">Smart</Badge>

    - **Welcome Messages** — Customizable greetings for new members
    - **CAPTCHA Verification** — Math or text-based verification for new users
    - **Auto-Approve** — Automatically approve join requests
  </Card>

  <Card title="Utilities" icon="settings">
    <Badge>Built-in</Badge>

    - **Multi-Language** — Supports English, Spanish, French, Hindi, Russian, Portuguese, and Indonesian (extensible)
    - **Remote Management** — Manage groups from private messages
    - **Command Disabling** — Disable specific commands per group
  </Card>
</CardGroup>

## Architecture Highlights

<CardGroup cols={2}>
  <Card title="High Performance" icon="zap">
    <Badge variant="success">Go-Powered</Badge> Built in Go with concurrent processing for handling high message throughput.
  </Card>
  <Card title="Scalable Caching" icon="database">
    <Badge variant="success">Redis</Badge> Redis-based caching with stampede protection via singleflight.
  </Card>
  <Card title="PostgreSQL Database" icon="table">
    <Badge variant="accent">Reliable</Badge> Robust data storage with automatic migrations and connection pooling.
  </Card>
  <Card title="Observability" icon="activity">
    <Badge>Built-in</Badge> Prometheus metrics and OpenTelemetry distributed tracing.
  </Card>
  <Card title="Docker Ready" icon="server">
    <Badge variant="warning">One Command</Badge> Easy deployment with Docker Compose, multi-arch images on GHCR.
  </Card>
</CardGroup>
