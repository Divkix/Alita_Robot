Alita Robot is a free, open-source Telegram group management bot. It removes
spam, keeps the chat readable, and gates new members behind a check before they
can post. Add it once, then enable only the checks you want for that group.

## What it does

Grouped by the job you are hiring the bot for. Each section links to the commands
that do the work, so you can check the details before enabling anything.

### Moderation

- Ban, kick, mute, warn, and temporarily restrict members: [bans](/commands/bans/), [mutes](/commands/mutes/), [warns](/commands/warns/).
- Delete messages in bulk: [purges](/commands/purges/).
- Let members bring a message to an admin's attention: [reports](/commands/reports/).

### Anti-spam

- Flood control that mutes, kicks, or bans after too many messages: [antiflood](/commands/antiflood/).
- Word and phrase blacklists with a configurable action: [blacklists](/commands/blacklists/).
- An optional join check against the CAS and lols.bot spam databases: [spamdb](/commands/spamdb/).
- Locks for links, forwards, stickers, media, and other message types: [locks](/commands/locks/).
- Anti-raid mode for mass joins: [antiraid](/commands/antiraid/).

### Onboarding

- A captcha challenge, math or text, before a new member can post: [captcha](/commands/captcha/).
- Welcome and goodbye messages with placeholders: [greetings](/commands/greetings/).
- Approved members who skip the flood, blacklist, and captcha checks: [approvals](/commands/approvals/).

### Logs

- Send admin actions to a dedicated log channel: [log channels](/commands/logchannels/).

### Notes, filters, and rules

- Save notes and recall them with a hashtag: [notes](/commands/notes/).
- Keyword filters that answer automatically: [filters](/commands/filters/).
- Set the group rules and show them on demand: [rules](/commands/rules/).
- Pin and unpin messages: [pins](/commands/pins/).

### Fit it to your group

- Pick a language for the group or for yourself: English, Spanish, French, Hindi, Indonesian, Portuguese, or Russian — [languages](/commands/languages/).
- Turn a single command off for one chat: [disabling](/commands/disabling/).
- Everything else, command by command: [command reference](/commands/).

## Get started

<Steps>
  <Step title="Add Alita and confirm the permissions">
    Use the [add-to-group link](https://t.me/Alita_Robot?startgroup=botstart&admin=change_info+delete_messages+restrict_members+invite_users+pin_messages+promote_members) or the button above, pick the group, and accept the permissions Telegram shows. They are the rights Alita checks before it acts.
  </Step>
  <Step title="Set the rules and a welcome">
    ```
    /setrules Be kind. No spam, no unsolicited links.
    /setwelcome Welcome {mention}! Please read /rules before chatting.
    ```
  </Step>
  <Step title="Turn on the checks you want">
    ```
    /captcha on
    /captchamode math
    /setflood 5
    /setfloodmode mute
    ```
  </Step>
</Steps>
